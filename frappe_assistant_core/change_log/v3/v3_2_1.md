## Version 3.2.1

### Fixes

- **Prepared reports work on the latest Frappe 16** — Frappe 16 renamed the function FAC
  used to find a finished prepared report, so on the current version every prepared
  report (Stock Balance, General Ledger and other large reports) failed. **If you run
  Frappe 16, upgrade before you next update Frappe.**
- **"Needs you" counts only real approvals** — a document whose only step left is Cancel,
  such as an approved Purchase Order, is no longer counted as waiting for you. Asking
  about the card gives the same total as the card.
- **Stock cards name your company** — late purchase orders, pending material requests
  and items below reorder level ask FACO about your company, so the answer matches the
  number on the card.
- **Dry runs never write** — a validate-only check is always rolled back, and a rename
  the update tool would refuse is no longer offered for approval.
- **Stalled answers are reported** — a turn that stops making progress says what it
  left behind instead of waiting forever.
- Signed-out visitors to FAC Chat are sent to the login page with a temporary redirect,
  so the browser does not keep redirecting after you sign in.

### Improvements

- **Safer customisations** — FAC refuses to save an active Server Script while server
  scripts are switched off on the site, instead of saving one that stops documents from
  saving. A script report saved while scripts are off gets a warning.
- **Readable customisation approvals** — approval cards show the full code, child tables,
  where a new custom field will appear on its form, and conditions in plain words.
- **Links to what changed** — created and updated records link to Desk, and a
  customisation links to the form it changes.
- **Customisation skills** — guided server scripts, client scripts, print formats,
  custom reports and notifications, each explained in plain language and confirmed
  before anything is written.
- **Your model choice is remembered** — the model you pick in FAC Chat is saved to your
  account and used in the widget and on your other devices.
- **FAC Chat on a phone** — no zoom when you tap a field, wide tables fit the screen,
  the conversation has more room while you type, the model button shows the model's
  name, one tap sends while the keyboard is open, links to your site stay in the app,
  and there is no gap under the home greeting.

### Upgrade notes

- Run `bench migrate`. It adds the saved-model field to FAC Chat User Preferences and
  installs the new customisation skills.
