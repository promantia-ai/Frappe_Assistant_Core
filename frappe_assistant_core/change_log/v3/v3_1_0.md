## Version 3.1.0

### Security

- **`run_python_code` hardened** — every read in the sandbox is permission-checked,
  code is validated before it runs, and file and pickle loaders are no longer
  reachable. **Upgrade promptly.**
- **Data tools are for System Managers** — `run_python_code` and
  `run_database_query` now require the System Manager role.

### Features

- **Agents and workflows** — tool and loop nodes in the builder, a runtime user per
  workflow, clearer run history, and templates that set up their own trigger.
- **FAC Chat** — a thinking level selector (Off to Max), every file in a
  conversation visible to the model, and the Desk widget rebuilt on FAC Chat's own
  components.
- **Tools** — `document_action` (formerly `submit_document`) can also cancel and
  amend; `list_documents` pages with `offset`; `generate_report` takes `max_rows`.

### Fixes

- Stop and Continue in chat behave reliably, write tools say why a permission was
  denied, and imports such as `from collections import Counter` work in
  `run_python_code`.

### Upgrade notes

- `analyze_business_data` is removed. `submit_document` still works as an alias
  for one more release; update prompts and MCP configs to `document_action`.

Full release notes: https://github.com/buildswithpaul/Frappe_Assistant_Core/releases/tag/v3.1.0
