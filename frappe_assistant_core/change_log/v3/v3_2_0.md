## Version 3.2.0

### Security

- **`list_documents` respects field permissions** — a field above your permission
  level, or one FAC withholds for your role, can no longer be used in filters,
  ordering or expressions, and `get_doctype_info` leaves it out. **Upgrade promptly.**
- **Approvals only show what you can open** — `get_pending_approvals` lists only
  documents you have access to.
- **Memory consent is asked for, not assumed** — users whose memory was switched on
  by default are asked once to keep it on or turn it off.

### Features

- **A new FAC Chat home** — a "Needs you" section with approvals and signals from
  accounts, sales, stock and HR, page-aware starters in the Desk widget, and cards
  you can hide inline and manage in Settings > Home page.
- **Projects and chat history** — group conversations into projects with their own
  instructions, documents and memory; rename, search, move and page through every
  conversation.
- **FAC Bot in Raven** — turn it on in FAC Admin and ask FACO from a Raven DM or
  mention; it answers as you, streams its reply, and stops when you delete it.
- **The widget beyond Desk** — switch the FAC Chat widget on for other Frappe apps
  from FAC Admin; it knows which page you are on.
- **FAC Chat tools** — reply to Helpdesk tickets, send CRM emails, log CRM activity
  and convert CRM leads, each behind an approval card that previews the email; read
  Insights dashboards and charts.
- **Finding data** — the assistant finds reports by what you asked, knows where a
  topic's data lives, and `list_documents` returns grouped totals.
- **FAC Admin settings** — edit each settings group in place from a new Settings tab.
- **Install FAC Chat as an app** from the browser (PWA).

### Fixes

- Generated PDFs render consistently, including on Frappe v16; chat charts are
  legible in dark mode; Mermaid diagrams render in strict mode; billing phone
  numbers keep the chosen country code.

### Upgrade notes

- Run `bench migrate`. It adds the FAC Chat Conversation, FAC Chat Project and FAC
  Widget Embed App DocTypes and creates a conversation record for existing chat
  history.
- Project documents and project memory need an up-to-date FAC Cloud; on an older
  one, FAC Chat says so instead of failing.
